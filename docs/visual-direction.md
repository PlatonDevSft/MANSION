# Mansion visual direction

The second user reference (TradeHub) is the primary layout/material reference; the product name remains Mansion.

- Near-black background, restrained emerald highlights, obsidian hero sculpture and reflective glass.
- Lightweight Manrope hero typography, compact search/header, consistent fine-line navigation.
- Russian feature cards with a larger active journal card, keyboard/swipe/arrow controls and reduced-motion support.
- Statistics below the carousel, retaining real local aggregation and explicit demo labels.
- Responsive treatments at 375, 768, 1024, 1440 and 1920 pixels.

`src/app/redesign.css` contains the material/layout layer over the existing application tokens and forms. Illustration sources are generated artwork, not screenshots of the references. Optimized WebP assets in `public/images` total about 310 KiB:

- `obsidian-hero.webp`: regenerated following feedback about ring intersections; original two-ring composition retained; ring occlusion corrected without replacing the original rock.
- `feature-sculptures.webp`: three-column asset sheet (solid anatomical graphite AI brain / journal / community), displayed without changing aspect ratios. Strategy/knowledge/copy/economy currently reuse these material studies.

The search filters navigable sections; it does not claim to index personal trades. Ctrl/Cmd+K focuses it. The source reference is visual direction, not a claim of a pixel-identical copy.

No Git push, deployment or environment publication is performed as part of this iteration.
